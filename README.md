# 红薯工作台 · XHS Studio

本机运行的小红书采集控制台。奶油纸底、墨线描边、网点与彩色贴纸组成的明亮漫画风格，上下分区：上方是可自由浏览网页的内嵌浏览器，下方是任务控制和「采集设置 / 运行状态 / 采集记录 / 运行日志」。支持关键词搜索、指定链接、登录接管、暂停/继续/停止、失败重试，以及 JSON / CSV / Markdown / ZIP 导出。

> 本项目用于个人资料整理与经过授权的内容备份。使用者应遵守目标平台规则、著作权与隐私要求；项目不提供验证码绕过、浏览器指纹伪装、代理池或风控规避能力。

标题使用漫画感的站酷快乐体，正文使用霞鹜文楷；字体由本机静态资源提供，无需安装系统字体或连接字体 CDN。来源与开源许可见 `static/fonts/`。样式仅作用于工作台和浏览器外框，不改变小红书实际网页的颜色和字体。

## 启动

需要 Python 3.10+ 和 Chrome 或 Edge。Windows 双击 `start.cmd`，或在本目录执行：

```powershell
.\start.ps1
```

首次启动创建本地 `.venv` 并安装依赖。打开终端提示的 **http://127.0.0.1:8765**。

一键启动使用 `requirements.lock.txt` 中已验证的固定版本，`requirements.txt` 保留兼容范围供开发升级使用。

手动安装和启动：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_console.py
```

端口被占用时追加 `--port 8766`。旧命令 `python Information_xhs.py` 也启动新版工作台。原脚本保留在 `legacy/Information_xhs.py` 供对照。建议一直使用同一虚拟环境。

## 使用流程

1. 调整关键词、搜索时间、最多篇数、间隔和本地保存位置。默认写入项目内 `Information/`，也可以输入绝对路径或点击「选择文件夹」。首次启动读取旧 `parameter.txt`，之后使用页面保存的配置。
2. 点击「打开浏览器」进入通用空白页，地址栏可访问任意网页。画面来自实际运行的浏览器，可以点击网页输入框直接输入中文、粘贴、滚动和拖动。
3. 点击「开始采集」后，程序一定先进入小红书首页并检查本机登录会话；未登录时任务停在首页，完成登录并点击「已处理，继续」后才进入搜索或详情页。关键词模式搜索新链接再逐篇读取；链接模式仅处理输入链接。每批受「最多篇数」限制。
4. 需要操作页面时点击「接管操作」或暂停。出现登录或验证时任务会等待，由你在页内处理，完成后点击继续；程序不会自动绕过验证或访问限制。
5. 完成或停止后下载报告。失败或部分完成的笔记可重试；「跳过已保存」允许后续执行时从未完成内容继续。

内嵌区通过同源 iframe 承载操作界面，使用 Chrome DevTools Protocol 串流实际浏览器画面并传递输入，不是将目标网站直接作为跨域 iframe，也不是静态预览。视口按容器自适应，不额外打开浏览器窗口。支持前进、后退、刷新、地址导航、点击、双击、拖拽、滚动、中文输入法及显式粘贴；复制/剪切网页选区暂不支持。断线时标记最后一帧并自动重连。采集运行时只读，暂停后才允许手动输入，恢复前释放按键并等待输入队列完成。

地址栏可访问任意有效 HTTP/HTTPS 网页，包括自定义端口、IPv6 和本地开发页面；普通域名默认补 HTTPS，localhost/回环地址默认 HTTP。不会接受 file/javascript/data 等非网页协议或内嵌账号密码。自由浏览与采集规则独立：采集仍只处理小红书笔记。

默认开启「直连网络」，受控 Chrome/Edge 会使用 `--no-proxy-server` 忽略系统 HTTP/HTTPS/PAC 代理。关闭后跟随系统代理。该设置只控制浏览器代理层，不能绕过 VPN、TUN、网卡或路由器层的网络出口，也不会尝试规避平台安全验证。

默认「高清」以 2× 像素密度原生采集画面（例如 1100×640 的网页视口对应 2200×1280 图像），JPEG 质量 92、最高约 8 帧/秒，并非放大低清图片。需要更轻量的动态画面时可切换「流畅」：1× 像素密度、JPEG 质量 80；选择会保存在本地。两种模式保持网页布局与点击坐标不变。高分辨率会增加本机浏览器的处理开销，实际刷新速度取决于页面与设备。

同一服务同时打开多个工作台页面时，最宽的已连接浏览器区域决定共享网页视口；较窄页面只等比缩小显示，不会再把宽屏页面压成手机宽度或产生大面积左右留白。

浏览器默认已加高，可拖动底部「调整高度」或用上下方向键微调；宽度不变。高度记在当前浏览器本地，点击「恢复默认」回到自适应高度。采集进行中锁定高度与画质切换，暂停后可调整。

## 参数

| 参数 | 意义 |
| --- | --- |
| 关键词 | 搜索词及资料集目录名 |
| 模式 | 搜索关键词，或指定帖子链接 |
| 搜索时间 | 搜索时间上限，1–3600 秒，无新结果时提前停止 |
| 最多篇数 | 本次待处理笔记上限，1–500 |
| 采集间隔 | 滚动及相邻笔记等待时间，1–60 秒 |
| 页面超时 | 页面读取等待上限，5–120 秒 |
| 重试次数 | 失败后的自动重试次数，0–3 |
| 下载图片 | 保存图片或视频封面，不下载视频文件 |
| 跳过已保存 | 同一资料集按帖子 ID 跳过已完整保存的记录 |
| 本地保存位置 | 默认 `Information`（项目内相对目录）；支持本机绝对路径和原生文件夹选择器，不接受网络共享、设备路径或越出项目的相对路径 |
| 浏览器 | 自动选择本机 Chrome / Edge，或手动指定 |
| 仅在页内显示 | 默认开启；使用屏幕外的普通浏览器窗口串流到工作台，不启用容易被目标站点限制的 Chromium 无头模式；关闭后同时显示本机窗口 |
| 直连网络 | 默认开启，忽略系统 HTTP/HTTPS/PAC 代理；VPN/TUN 等网络层出口仍会生效 |
| 图片命名 | 标题、帖子 ID 或正文首行，始终带帖子 ID 避免重名 |

配置字段 `headless=1` 为兼容旧版本继续保留，但新版含义是“仅在页内显示”：浏览器仍以普通窗口模式渲染，只将窗口放到屏幕外并通过 CDP 串流，不再传入 Chromium 的 `--headless` 参数。旧 `chrome_profile/` 不自动迁移；新版使用独立 `runtime/profiles/`，需要首次登录一次。

## 代码与结果

```text
xhs/
├── run_console.py               本地服务入口
├── Information_xhs.py           兼容入口
├── xhs_console/
│   ├── server.py                HTTP / WebSocket API、静态页面、文件下载
│   ├── manager.py               单线程浏览器所有权、任务状态及操作队列
│   ├── browser.py               小红书搜索、访问检测及浏览器控制
│   ├── remote_browser.py        CDP 实时画面、直接输入与视口自适应
│   ├── extract_note.js          页面状态数据 + DOM 解析
│   ├── config.py                参数校验、旧格式导入
│   └── storage.py               图片、去重记录与报告导出
├── static/                      原生 HTML/CSS/JS，无需 Node 构建
├── runtime/                     本地配置、浏览器会话、持久化记录
├── Information/<关键词>/console/ 默认报告及图片位置（可在页面修改）
└── tests/                       单元、API、状态流程及浏览器测试
```

旧资料保持原样，采集结果写入 `<本地保存位置>/<关键词>/console/`。默认根目录为项目内 `Information/`；自定义保存位置使用独立运行索引，避免同名关键词互相覆盖。正文和图片进度逐篇落盘；导出从完整记录重新生成，避免重复追加。图片保持原始顺序，下载失败保留正文并标为部分完成。缺失日期保留为空或原始显示文本，不伪造为当天。

## 小红书适配与验证范围

- 同一个持久浏览器会话贯穿登录、搜索与详情读取。
- 优先读取已加载页面 `__INITIAL_STATE__.note.noteDetailMap`，回退详情 DOM；推荐列表不被当作正文。
- 保留链接访问签名，按帖子 ID 去重，支持常见详情链接及官方短链。
- 页面等待、下载超时、有限重试、篇数上限；登录/验证/访问限制等待人工处理。
- Selenium 由一个工作线程持有；独立 CDP 连接负责画面与人工输入，通过状态锁和输入屏障与采集互斥。

已使用独立 Edge 浏览器验证当前小红书公开首页、真实公开笔记读取及搜索登录拦截。个人账户登录后的批量搜索需要在本机完成登录后实测。页面结构或访问条件变化时，错误会在日志和画面中显示。功能不包含评论、OCR、视频转写或完整视频下载。

服务仅监听 `127.0.0.1`。本地配置、浏览器数据、签名参数和采集内容由 `.gitignore` 排除。不要把整个运行目录作为静态网站对外托管。

## 开发验证

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

真实浏览器 fixture 测试（独立临时配置，不使用个人账户）：

```powershell
$env:XHS_RUN_BROWSER_TESTS = '1'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

前端交互协议与真实页内操作验收（测试均只访问本地测试页）：

```powershell
node --test tests/browser_viewer_protocol.test.cjs
$env:XHS_VIEWER_E2E = '1'
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_browser_viewer_e2e.py -v
$env:XHS_THEME_TESTS = '1'
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_console_layout.py -v
```

Node 仅用于开发测试，运行工作台不需要 Node。全链路测试使用随机本地端口及两个临时浏览器，验证 iframe、WebSocket、真实中文输入、拖拽与容器自适应；漫画界面测试检查本地字体加载、各标签与模式的溢出及空白。系统输入法候选词选择需人工验收。

驱动由 [Selenium Manager](https://www.selenium.dev/documentation/selenium_manager/) 自动准备；本地 API 使用 [FastAPI](https://fastapi.tiangolo.com/)。
